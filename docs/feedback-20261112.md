## 明确反馈真正生效

之前 `irrelevant` 只扣有限分数；高分论文仍可能保留 `consider`，作者栏目又独立于阈值。
现在只对用户明确标记的**具体论文**设置 `feedback_suppressed`：全局不相关或全局hold
通过统一出口挡住综合推荐、作者动态、经典/语义补漏，不再记录成已发送。
不相关仍不训练负方向偏好，不降低同方向其他论文。Scoped反馈仍局限于对应方向，
reset/正反馈清除显式抑制标记。撤稿/更正事件在独立通知路径中，不被普通推荐抑制。

GitHub issues是当前反馈输入，关闭issue不丢反馈（工作流读取 `state=all`）。本次不复制
反馈到更高优先级的config/feedback.yaml，避免将来用户的reset被静态配置覆盖。
不改写历史周报、画像包、已发记录；新规则在后续运行生效。
