# 重点作者追踪

2026-09-17 起，ZotWatch 在主题查询和期刊补抓之外，增加独立的作者发现入口。
名单来自全库元数据、语义检索和引用关系审计，而非仅按知名度或用户点名排列。

## 配置与身份

`config/authors.yaml` 当前启用 58 位作者、65 个 OpenAlex 作者 ID。
部分同一作者的分裂档案经库内代表作及机构交集核对后保留多个 ID。
每位作者记录关注理由、核验日期和代表作 DOI；常见名字另有逐篇机构 ID 条件。
完整名单及证据见 [tracked-authors.md](tracked-authors.md)。

实际查询使用 `authorships.author.id`，不以姓名字符串自动认定身份。返回论文必须
再次匹配配置的作者 ID；有机构限制时还必须匹配该署名的机构。机构不全或作者
迁移到未登记单位可能导致漏收，可在核验后更新。OpenAlex 自身也可能存在合并、
拆分错误，书目交叉核对不是绝对身份保证。

## 发现、筛选和展示

- 作者按 10 个 ID 一组查询最近 30 天的作品，默认最多 3 页，每页 100 条。
- 缓存命中不会跳过作者新作抓取；禁用作者会清除缓存中的旧关注标签。
- 已标记撤稿的记录和数据集/补充材料不进入作者新作，避免将数据文件当论文。
- 普通主题筛选继续适用。身份匹配的关注作者另有受约束的力学主题入口：标题或
  摘要至少命中塑性、本构、硬化、断裂准则、损伤演化等词；明确离题项依然排除。
- 命中作者在原有相关性评分上增加 0.03，不改变其他文献的基础权重。
- HTML 增加“重点作者新作”区，按发表时间列最多 20 篇。它独立于综合推荐前
  20 篇及综合评分阈值，但仍经过主题、日期及已有文库去重；不代表这些新作都
  被评为必须阅读。
- RSS 合并综合推荐与作者新作并按 DOI 去重；邮件仍使用已有 HTML/RSS 附件。
- 显式使用 `--push` 时，仍只将综合推荐部分推送到 Zotero，不擅自导入作者区全部论文。

## 维护

新增作者应先用代表作 DOI 对应的署名、机构、作者 ID 核验，再编辑作者配置。
不要只根据姓名搜索第一条结果填写 ID。同样，不要根据某篇论文撤稿而自动删除
该作者所有其他作品；论文状态和作者身份应分别处理。

6 位候选暂未启用，见完整名单的待核验区。该状态表示本次身份数据不足，不是
对科研贡献的负面评价。

## 验证

`tests/test_author_watch.py` 覆盖身份与机构匹配、同名排除、缓存更新、作者新作
独立展示、DOI 去重、评分加分、主题筛选、撤稿与数据集处理。
全套命令：`python -B -m unittest discover -s tests -v`。

有限在线烟测针对 6 位作者，在当前 30 天窗口核对发现与筛选流程。该抽样不等于
保证 58 位作者的所有论文都被聚合数据库收录。
